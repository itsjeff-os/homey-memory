# Home System Sources

Human-readable home system docs belong here before ingestion into Chroma.

Suggested subfolders:

- `inventory/` for devices, rooms, lighting, hubs, and room mappings.
- `network/` for topology, Cloudflare, Unifi, switches, and connectivity.
- `compute/` for Mini PC, Docker, power, backups, and local runtime setup.
- `runtime/` for n8n, Supabase, Zep, Chroma, queues, and agent operations.
- `rituals/` for routines, preferences, overrides, and behavioral patterns.
- `archives/` for Notion exports and snapshots.

Docs in this folder are treated as retrievable source material, not automatically
trusted runtime truth until deduplicated and indexed.
