# Home Assistant Canonical Staging

Cleaned, migration-ready Home Assistant material lives here. Nothing in this
folder is live until copied into the actual Home Assistant config after:

1. parser validation,
2. Home Assistant config validation,
3. behavior comparison against the raw snapshot,
4. explicit deployment approval.

## Package Direction

The staged package domains are:

- `context`
- `presence`
- `lighting`
- `climate`
- `ai_actions`
- `system_health`
