# Architecture — History

Architectural Decision Records (ADRs) and historical design snapshots.

## Structure

```
history/
├── 0001-<title>.md
├── 0002-<title>.md
└── ...
```

## ADR Template

```markdown
# NNNN — Title

**Date:** YYYY-MM-DD
**Status:** Proposed | Accepted | Deprecated | Superseded by [NNNN]

## Context
What situation or problem prompted this decision?

## Decision
What was decided?

## Consequences
What are the positive and negative outcomes of this decision?
```

Copy this template into a new numbered file when recording a decision.
