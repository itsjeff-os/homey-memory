# Architecture — References

External papers, diagrams, blog posts, and other reference material that inform the architecture.

## Structure

```
references/
├── <topic>/           # Grouped by topic or system
│   └── *.md           # Notes, links, or summaries
└── *.md               # Standalone reference notes
```

## Adding a Reference

Create a markdown file with:
- **Title** and source URL
- A short summary of why it is relevant
- Any key takeaways or decisions influenced
